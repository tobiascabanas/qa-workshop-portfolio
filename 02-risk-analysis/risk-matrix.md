# Risk Matrix

| ID | Riesgo | Impacto | Probabilidad | Nivel | Justificación |
|----|--------|---------|--------------|-------|---------------|
| R1 | El sistema podría permitir realizar compras sin completar el proceso de pago | Alto | Alta | Crítico | Afecta directamente los ingresos del negocio |
| R2 | Los precios de productos podrían mostrarse incorrectamente en el carrito | Alto | Media | Alto | Genera pérdida económica o desconfianza del usuario |
| R3 | El sistema podría fallar al procesar múltiples productos en el carrito | Medio | Alta | Alto | Flujo crítico con alta interacción del usuario |
| R4 | La API podría devolver respuestas incorrectas o incompletas para consultas de inventario | Medio | Media | Medio | Impacta integraciones con otros sistemas |
| R5 | El sistema podría permitir registros con datos inválidos o incompletos | Bajo | Media | Bajo | Afecta calidad de datos pero no directamente ingresos |
